# Публикация DUMRAUF.RU на REG.RU

## Текущий frontend
1. Проверить GitHub Actions build.
2. Скачать production artifact dumrauf-ru-production.
3. Сделать резервную копию текущего содержимого /www/dumrauf.ru/.
4. Загрузить содержимое артефакта согласно DEPLOY-REG-RU.md.
5. Проверить прямое открытие:
   - https://dumrauf.ru/privacy-policy
   - https://dumrauf.ru/personal-data-consent
   - https://dumrauf.ru/cookie-policy
   - https://dumrauf.ru/terms
6. Проверить мобильную версию, ссылки в footer и возврат на главную.

## Важное ограничение
Этот репозиторий содержит статический React/Vite-сайт. Он не содержит приложения с backend-аутентификацией, users database, allowlist API, подписками или платёжным модулем. Требования к ним описаны в docs/ACCESS_AND_BILLING_SPEC.md; это спецификация, а не реализованная функция.

До запуска backend необходимо подтвердить фактическую поддержку PHP/БД на REG.RU либо выбрать подходящую серверную инфраструктуру, проверить расположение БД, журналов, резервных копий, email-провайдера и обработчиков. Не копировать PHP-пример поверх React index.html.
