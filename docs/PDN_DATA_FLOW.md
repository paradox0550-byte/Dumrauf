# Карта потоков персональных данных — DUMRAUF.RU

**Проверенная реализация:** контактный CTA использует ссылку mailto. В репозитории не обнаружены собственная серверная форма отправки заявок, API приёма заявок или база заявок.

## Текущие потоки
1. Посетитель открывает статический сайт на REG.RU.
2. Браузер загружает HTML, JS и CSS.
3. При нажатии на контактную ссылку открывается почтовый клиент пользователя; пользователь самостоятельно формирует и отправляет письмо.
4. Письмо поступает в почтовый сервис адресата. Провайдера и место хранения необходимо подтвердить.
5. Хостинг может вести технические журналы. Их состав, место хранения и срок необходимо подтвердить у REG.RU.

## Не реализовано
- API /api/lead;
- серверная фиксация согласий;
- база данных заявок;
- веб-форма удаления данных;
- cookie consent manager;
- автоматическая очистка заявок.

## Перед подключением формы
Спроектировать серверную часть, определить российскую первичную базу данных, договоры с обработчиками, модель доступа, сроки хранения, аудит событий и процедуру реагирования на запросы субъектов. Не включать сбор данных до завершения этих шагов.
